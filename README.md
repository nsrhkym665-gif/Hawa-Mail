# Hawa Mail — النسخة المجانية

هذه النسخة تعمل كواجهة GitHub Pages وتستخدم خدمة smails.dev المجانية لاستقبال البريد المؤقت عبر API، لذلك لا تحتاج دومينًا خاصًا أو Cloudflare Worker.

## مهم
- الخدمة خارجية ومجانية ولا تحتاج حسابًا أو مفتاح API بحسب توثيقها.
- البريد استقبال فقط.
- الصناديق تنتهي تلقائيًا بعد فترة من عدم النشاط.
- بعض المواقع قد تمنع عناوين البريد المؤقتة أو لا ترسل إليها.
- استخدمها للاختبار والخصوصية المشروعة، وليس لتجاوز أنظمة الحماية أو إساءة الاستخدام.
